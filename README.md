# Excel Data Cleaning & Functions Practice Project

## 📌 Project Overview
This project focuses on practicing **Excel functions** on a dummy dataset.  
The objective is to clean raw data and apply commonly used Excel formulas to prepare the dataset for analysis.

---

## 🧾 Dataset Details
- Type: Dummy dataset for practice
- Rows: 30
- Data issues included:
  - Duplicate entries
  - Extra spaces in text
  - Inconsistent text length
  - Missing and invalid values

---

## 🛠 Tools Used
- Google sheets

---

## 🔧 Excel Functions Used

The following Excel functions were applied during the data cleaning process:

### 1️⃣ COUNTIF
- Used to count duplicate or repeated values in specific columns
- Helped identify duplicate records

### 2️⃣ LEN
- Used to calculate the length of text in cells
- Helped detect incorrect or inconsistent data entries

### 3️⃣ LEFT / RIGHT
- Used to extract specific characters from text
- Helpful for cleaning IDs, codes, or formatted text

### 4️⃣ CONCATENATE
- Used to combine multiple columns into a single column
- Helped create full names or merged text fields

### 5️⃣ TRIM
- Used to remove extra spaces before, after, and between words
- Improved text consistency across columns

---

## 🔍 Data Cleaning Steps Performed

1. Removed duplicate records using **Remove Duplicates**
2. Used **COUNTIF** to identify duplicate values
3. Applied **TRIM** to clean extra spaces
4. Used **LEN** to validate text length
5. Extracted text using **LEFT / RIGHT**
6. Combined columns using **CONCATENATE**
